# MoGe-3D Scanner Releases

All release binaries and historical archives have been migrated to official [GitHub Releases](https://github.com/1kaiser/binary_live3dscanner/releases) to optimize git clone size and support large ML model binaries.

---

### Latest Release

- **[MoGe-3D Scanner v2.0 (Latest)](https://github.com/1kaiser/binary_live3dscanner/releases/tag/v2.0)**
  - Direct APK: [`MoGe3DScanner_v2.0.apk`](https://github.com/1kaiser/binary_live3dscanner/releases/download/v2.0/MoGe3DScanner_v2.0.apk) (457 MB)
  - Features:
    - **MoGe-3 Metric Geometry**: Monocular metric depth and 3D coordinate estimation via LiteRT INT8 ViT-L model.
    - **2D Thermal Fusion**: Registered 16-bit radiometric thermal heatmap overlay via 4-corner perspective homography.
    - **Triple 3D GLB Generation**: Simultaneous generation and in-app dynamic switching of Fused 3D, Pure Thermal 3D, and Pure RGB 3D models.
