👑 Guided Step-by-Step Workflow

Welcome to the MoGe-3D & Thermal Scanner Studio. This browser application provides metric 3D point cloud generation and radiometric thermal sensor fusion completely inside your browser.

📋 Step-by-Step Pipeline

  • Step 1: Model Initialization & Download:
    Click 🧠 Model & Worker on the top-right. The Web Worker automatically checks your local browser cache. If not yet cached, click ⬇️ Download Model from Hugging Face to fetch the official moge3_dense_stage_dynamic_int8.tflite (323.8 MB) with live progress tracking. Once stored, it loads with 0ms delay on all future visits.
  • Step 2: Load Default Image or Upload Custom Photos:
    Click ⚡ Instant Demo to immediately populate calibrated mobile captures (RGB, Thermal, and Calibration Quad). Or use the left action buttons (📷 Upload RGB Photo, 🌡️ Upload Thermal Image, 📐 Upload Calibration JSON) to inspect your own targets.
  • Step 3: Interactive 4-Corner Homography Registration:
    Open the 📐 Calibration Quad drawer. Drag corner handles A, B, C, D on the live preview canvas to map the thermal field of view exactly onto the optical perspective. Rotate by 0°/90°/180°/270° or flip horizontally if using an external USB thermal camera.
  • Step 4: Execute 3D Metric Inference:
    Click ✨ Step 4: Run 3D Metric Inference on the left rail. The Web Worker synthesizes the metric point cloud in true physical meters, generates glTF 2.0 binary .glb buffers, and loads them into Google <model-viewer> without UI stutter.
  • Step 5: Multi-Modal 3D Exploration:
    Use the bottom pill bar to switch between 📷 RGB Optical, 🌈 Fused Multi-Modal, 🌡️ Radiometric Thermal, and 📐 2D Alignment. Toggle the 🔄 Turntable (10 FPS) standard (12s per full loop) for technical inspection, or click 💾 Export 3D Model to save the .glb file.

📐 Technical Invariants

  • Android Parity: Direct translation of Android's native Matrix.setPolyToPoly() via 2-triangle affine decomposition on 2D canvas.
  • Metric Unprojection: True physical metric units ($X, Y, Z$ in meters) de-quantized from MoGe-3 factorized coordinates.
