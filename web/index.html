👑 MoGe-3D & Thermal Scanner Web Studio

A pure client-side web application for desktop browsers providing monocular metric 3D point cloud reconstruction and 2D radiometric thermal alignment without server dependencies.

🚀 Quick Start

  • Instant Demo: Click the ⚡ Instant Demo button on the top-left to automatically load real mobile captures and pre-computed 3D models.
  • Custom Inputs: Upload your own RGB Photo, Thermal Image, and optional Calibration JSON exported from the Android app.
  • Interactive Turntable: Click 🔄 Turntable (10 FPS) to inspect models at the standardized 10 FPS technical rotation speed (12 seconds per full turn).
  • 4-Corner Perspective Calibration: Open the 📐 Calibration Quad panel on the top-right to adjust corners A, B, C, D and orientation angles to match any camera lens setup.
  • Export: Click 💾 Export 3D Model to save standards-compliant glTF 2.0 binary .glb point clouds.

📐 Technical Invariants

  • Homography Transform: Equivalent to native Android Matrix.setPolyToPoly() decomposed into two analytical affine triangles ($ABC$ and $ACD$) via 2D Canvas matrix transforms.
  • Metric Unprojection: Points are de-quantized into true physical coordinates in meters ($X, Y, Z$).
  • Model Viewer: Powered by Google <model-viewer> with full orbital control, touch gestures, and WebXR AR support.
